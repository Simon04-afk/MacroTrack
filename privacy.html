Datenschutzerklärung – Nährwerte

Stand: August 2026

Nährwerte ist eine selbst gehostete App: Diese Datenschutzerklärung beschreibt, was die App-Software technisch tut. Wer konkret "Verantwortlicher" für deine Daten ist, hängt davon ab, wer den Backend-Server betreibt, mit dem du die App verbindest (bei einer privaten Installation i. d. R. du selbst).

Welche Daten werden gespeichert?

  • Ohne Konto: Alle Angaben (Mahlzeiten, Ziele) bleiben ausschließlich lokal auf deinem Gerät (localStorage) und verlassen es nicht.
  • Mit Konto: E-Mail-Adresse und ein gehashtes Passwort (nie im Klartext) sowie deine geloggten Mahlzeiten (Lebensmittelname, Menge, Kalorien, Protein, Kohlenhydrate, Fett, Zeitpunkt) werden auf dem von dir konfigurierten Server gespeichert.

Weitergabe an Dritte

  • Open Food Facts (world.openfoodfacts.org): Barcode- bzw. Namenssuchen werden direkt von deinem Gerät aus an diesen offenen, gemeinnützigen Produktdatenbank-Dienst gesendet, um Nährwertangaben abzurufen. Es werden dabei keine Konto- oder Gesundheitsdaten von dir übertragen, nur der gesuchte Begriff bzw. Barcode.
  • Foto-Analyse (optional): Falls der Serverbetreiber einen Vision-KI-Anbieter konfiguriert hat, wird ein aufgenommenes Foto zur Analyse an diesen Anbieter übermittelt. Welcher Anbieter das konkret ist, legt der Serverbetreiber fest. Das Foto wird von unserem eigenen Server nicht dauerhaft gespeichert.
  • Keine Werbung, kein Tracking, kein Verkauf von Daten an Dritte.

Löschung

Unter Profil → Konto → Konto löschen werden dein Konto und alle serverseitig gespeicherten Mahlzeiten unwiderruflich entfernt. Lokale Daten auf dem Gerät kannst du über die Löschfunktion deines Betriebssystems (App-Daten löschen) entfernen.

Sicherheit

Passwörter werden gehasht (PBKDF2) gespeichert, die Sitzung läuft über ein zeitlich begrenztes JWT-Token. Der Serverbetreiber ist dafür verantwortlich, den Server über eine verschlüsselte Verbindung (HTTPS) und mit aktuellen Zugangsdaten zu betreiben.

Kontakt

Fragen zu dieser Installation richtest du an die Person oder Organisation, die den von dir genutzten Server betreibt (sichtbar unter Profil → Konto → Server-URL).
